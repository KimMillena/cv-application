## 🧠 What I Learned
- **React:** I learned that React is a library created by Facebook now Meta. It is a library used to build dynamic and interactive interfaces.
- **State/useState:** State is a collection of all the state/variables in an application, it controls how the application behaves. useState is a built-in hook in React that allows us to define a state/stateful variable in a functional component. It returns an array with two values which are the **current state value** and a **function to set or update the state value**. **(State is a components memory)**
- **props:** In React data transfers in one direction (unidirectional), from a parent component to a child components using props.
- **JSX:** JSX is a JavaScript syntax extension that allows us to write HTML-like code inside a JavaScript file.
- **Components:** Components are a reusable blocks of code/User Interface (UI).
- **keys** React keys allows React to uniquely identify which elements or items have been added, removed, or updated in the application.
- **Reconciliation** It is a process that React uses to efficiently update the DOM. It compares the previous virtual DOM to the new virtual DOM using the diffing algorithm to calculate the number of minimum changes needed before updating the real DOM.
